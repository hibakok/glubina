# Эволюционирующий универсальный аппроксиматор вычислимых функций

## Описание

Программа реализует эволюционирующий универсальный аппроксиматор, способный обучаться на парах входных-выходных данных и находить математическую формулу, которая аппроксимирует заданную функцию. Используется подход генетического программирования с эволюцией деревьев выражений.

### Формат входных данных

Файл данных должен иметь следующий формат:
- Каждая строка содержит пару "входные данные | выходные данные"
- Разделитель - вертикальная черта "|"
- Числа разделены пробелами
- Поддерживаются комментарии (строки начинающиеся с #)

Пример файла `data.txt`:
```
# Пример: функция f(x, y) = x^2 + y
1.0 2.0 | 3.0
2.0 3.0 | 7.0
3.0 4.0 | 13.0
0.5 0.5 | 0.75
```

### Параметры эволюции

- **Размер популяции**: Количество особей в каждом поколении (по умолчанию 50)
- **Количество поколений**: Сколько поколений эволюционировать (по умолчанию 100)
- **Вероятность мутации**: Вероятность изменения узла дерева (по умолчанию 0.1)
- **Вероятность кроссовера**: Вероятность обмена поддеревьями (по умолчанию 0.7)
- **Количество элитных особей**: Сколько лучших особей сохранять без изменений (по умолчанию 2)
- **Максимальная глубина дерева**: Ограничение на глубину дерева выражений (по умолчанию 5)

## Архитектура

### Основные классы

1. **DataPair**: Представляет одну пару вход-выход
2. **Dataset**: Набор пар данных с методами загрузки, нормализации
3. **ExpressionTree**: Дерево выражений, представляющее математическую функцию
4. **Population**: Популяция особей для эволюции
5. **UniversalApproximator**: Главный класс, объединяющий все компоненты

### Поддерживаемые операции

- Бинарные: +, -, *, /, ^ (возведение в степень)
- Унарные: log, exp, sin, cos, tan

### Алгоритм эволюции

1. Инициализация случайной популяции деревьев выражений
2. Вычисление fitness (MSE) для каждой особи
3. Селекция (турнирная)
4. Кроссовер (обмен поддеревьями)
5. Мутация (случайное изменение узлов)
6. Элитизм (сохранение лучших)
7. Повторение шагов 2-6 заданное количество поколений

## Примеры использования

### Программный интерфейс

```python
from approximator import UniversalApproximator

# Создание аппроксиматора
approx = UniversalApproximator()

# Загрузка данных
approx.load_data('data/sample_data.txt')

# Настройка параметров
approx.set_params(
    pop_size=100,
    generations=200,
    mutation_rate=0.1,
    crossover_rate=0.8,
    max_depth=6
)

# Обучение
approx.train()

# Предсказание
result = approx.predict([2.0, 3.0])
print(f"Предсказание: {result}")

# Получение формулы
formula = approx.get_best_formula()
print(f"Формула: {formula}")

# Сохранение модели
approx.save_model('models/my_model.pkl')

# Загрузка модели
approx.load_model('models/my_model.pkl')
```
